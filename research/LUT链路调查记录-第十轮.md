# LUT 链路调查：前置调用边界与捕获模块初始化

日期：2026-10-18。接续[第九轮](LUT链路调查记录-第九轮.md)，只读分析同一官方原版 CP 2.01，材料完整指纹见[交接](HANDOFF.md)。未执行固件、连接相机或生成机内补丁。

本轮把前置调用对配置的显式访问缩小到标志条件，并连接了捕获 VFX 模块的初始化、选择和工作槽。**这没有完成用户 LUT 到照片 JPEG 的连接；全部调用/别名副作用、运行时选择值和缓冲身份仍未验证。**

## 1. 当前 `0x2b` 调用与其他调用要区分

第九轮找到 `0x381e98 → 0x382bd8`，其第 4 个参数指向包含查询回复的局部配置区。前置函数入口将这个指针从 `r3` 保存到 `fp`。

不能把函数所有分支套用到当前调用：

| 位置 | 已确认行为 |
| --- | --- |
| `0x382bea / 0x382bf4` | 测试标志位 1；当前 `0x2b` 进入相应处理段 |
| `0x382fb0` | 把配置指针保存到局部栈 `+0x24`；后续 `fp` 被用于其他值 |
| `0x382c9e / 0x382ca0` | 标志左移 25 位后 BPL；相当于检查原值的 `0x40` 位是否为零 |
| `0x382ccc` | 在 `0x40` 处理段读取配置 `+0x1c8` |
| `0x383280 / 0x383294` | 同一处理段重载保存的配置指针，把它作为通道参数传给 `0x37845c` |
| `0x384278` | 相关重入分支从局部栈重载标志与保存指针 |

当前 `0x2b` 不包含 `0x40`，因此跳过这一处理段。工具在两段已解码代码组成的有界图中验证：三个目标位置无约束时均有潜在路径；加入上述两处标志决策后，三者均无路径。

图中 `[0x383a14, 0x383aa0)` 为内联数据岛，明确排除。允许跨块的显式跳转，但不跨数据空隙虚构顺序执行。条件决策由核对过的调用标志、寄存器保持及重载提供，**没有自动求解其他条件**。

这个结果排除的是当前标志下已追踪的显式配置访问；被调函数按可能返回处理，没有因此审计其所有行为，也没有排除其他间接别名或异步写入。故 `query_address_preserved_across_all_calls_verified` 仍为 false。

## 2. 其他标志下确实存在可写准备入口

启用 `0x40` 的分支会把原配置指针传入 `0x37845c`。包装函数在入口栈取第 5 个参数，构造两个指针数组，其第一项分别是该指针 `+0x6c` 和 `+0xd8`，交给 `0x378648`。

准备函数按模块配置和非零条件，在所指区域的 `+0/+4/+8` 写字。第一项对应的潜在配置偏移为：

```text
0x6c, 0x70, 0x74, 0xd8, 0xdc, 0xe0；每项 4 字节
```

这些已知写入不与候选双字 `[+0xf0, +0xf8)` 重叠。但包装随后还调用 `0x43f404`，本轮没有穷尽下层行为，不能把上述范围当成整条处理链的完整写集，也不能称整份查询回复只读。

## 3. 捕获模块选择与初始通道值

模块选择函数入口 `0x37e0a4` 接收工作对象和初始化标志。**当初始化标志含 `0x20` 且相应成功分支继续时**：

1. `0x37e316` 传入参数 1，调用获取函数 `0xa0b72e`。
2. 获取函数对非零参数返回链接地址 `0x1a4e6a4`；零参数的另一个对象是 `0x1a4e558`。
3. 返回指针经局部栈 `+0x14`，最终写入工作对象 `+0x5bdc`。
4. 邻接 `+0x5be0` 写入的是 `0x37377c` 返回的伴随值，本轮未为它命名具体业务语义。

初始化代码对这两个对象分别设置 `+0x12c = 7 / 9`。通用基础构造 `0xa09faa` 不修改 `r0`、没有调用，返回原对象指针，因此可以对应初始化写入的对象，而不只比较常量。

这连接到第九轮包装 `0x378f28` 对模块 `+0x12c` 的读取：**所选对象的初始值为 9**，该值的分支把四个构造通道交给 VFX API 的第 2/3/4/5 个参数（r0 为第 1 项）。

这是条件式初始化和参数分派的静态连接。尚未核对初始化的全部调用者、运行时是否再次改写选择值、对象实例生命周期或用户 LUT 的接入；内部值 9 不能命名为某个相机拍摄模式。

## 4. 工具和验证

新增 [trace_capture_effects.py](trace_capture_effects.py)，在原版指纹限定和第九轮证据基础上核对上述关系；只输出偏移、数值和明确限制。两个顶层 true 仅表示当前显式路径排除和模块初始选择的静态连接；十项整体保持、运行、LUT/像素和设备结论为 false。

[potential_thumb_path](trace_lut_refresh.py) 新增可选 `branch_decisions` 和 `allow_gaps`，默认行为不变。只有已解码条件分支可以接收布尔决策；重复/重叠指令、非法决策及错误边界停止。该函数不推导决策来源，不跟踪调用副作用，不解释间接跳转/跳转表。

新增 [test_capture_effects.py](tests/test_capture_effects.py) 的 6 项合成测试，覆盖已取/未取条件边、返回阻断、分离块、禁止跨空隙顺序执行、错误决策拒绝、循环终止、输入不变及错误固件拒绝。研究测试 106 项，连同原项目 39 项和固定上游 8 项，合计 **153 项离线通过**。原版 CLI、拒绝覆盖/错误材料、旧工具默认报告一致性及固定资产检查通过；完整命令与收尾检查见[历史验证](../plan-history-through-14.md#第十轮实际验证命令)。本地报告：忽略目录 `research/output/capture-effects-v1.json`。
