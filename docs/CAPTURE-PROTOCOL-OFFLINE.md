# N3：固定读取请求与有界协议模型

第四十三轮新增 [captureprotocol](../lutphoto/captureprotocol.py)，第七十四轮修正文件/快照读取边界。它生成固定请求字节，接收调用方显式提供的读取结果，自身没有USB、认证或真实stop能力。保留旧类名`OfflineChannel`；如今合成会话和[原生采集装配](CAPTURE-FIRST-USE.md)均使用它，不能再据类名认定它仅用于演示。当前测试全为自制数据，本项目真实材料仍为0。

请求编码与材料策略继续依据QAQLeonard v2.1 `7e54d60b458847f1befa6cfd614fbf004b8b0b90`和ma1co Sony-PMCA-RE。文件/快照按长度接收与空传输规则参考QAQLeonard 3.0.3 `782785641ca9f8b984940c7274b48706219e0da4`共享运行时；固定文件摘要、复用范围及测试见[第74轮](../research/LUT链路调查记录-第七十四轮.md)，保留[署名及许可](../ACKNOWLEDGEMENTS.md)。构造时仍校验既有10成员加载链和14成员程序策略，不导入归档Python。旧安装器、固定锁、程序哈希、偏移与依赖保持不变。

## 固定能力与接收约束

| 项目 | 已实现的离线行为 |
| --- | --- |
| 请求白名单 | ProductInfo HASP；`(0x603,5)` 的 RAM/保存快照；AP/CP 与可选固定 68 UXC 的 Jiritsu 15 选择、17 读取。默认 7 项，包含资源共 143 项；没有任意路径/操作码、16/18、setter 或清理接口 |
| 文件选择 | 读取必须对应本模型先前成功的固定 select；成功读取后消耗选择。选择失败停止后续读取；不自动选择、重试或接受 missing 为成功 |
| 请求编码 | 小端 12 字节 Senser 头及固定命令体；单请求最多 1024 字节，序号从 1 开始，不循环；最多 512 次请求 |
| 服务响应轮廓 | 仅建模 PID 0336 的 12 字节头、最多 1 MiB/段；单次载荷读取最多 32 KiB。头必须完整，载荷可碎片返回；不同 read 的结果不能拼成一条无边界字节流 |
| 空传输/对齐边界 | 按声明长度收取有效内容，不在对齐块后主动排空；空传输在当前包头/数据阶段消费，不算载荷、不刷新期限。完成后不再主动读尾空包；若存在，留到下一次正常读取消费 |
| 单响应边界 | 头声明大小、累计分段字节和最大段数在读取该段载荷前检查；AP/CP 用固定原厂精确长度，快照最多 32 MiB，资源最多 1 MiB，HASP 恰好 88 字节 |
| 全程预算 | 同一个Budget/deadline贯穿所有请求、碎片和Sink。段声明先检查剩余载荷额度；另外累计请求、响应头和4字节状态，按最大读取长度预检线路额度；最多65,536个读取结果，包含空传输 |
| 主机保存 | 使用既有 Sink，分离 Jiritsu 状态字与文件载荷；完整响应后才 finish/同步及完整读回。测试把自制 CP 载荷保存到真实私人临时目录核对，失败仍保留部分文件 |

`next_read()`返回本次种类、最大长度及剩余总期限毫秒数。原始/原生所有者在每个阻塞调用前传入剩余期限，单次I/O还受5秒上限约束；不能对每次read重置全程期限。真实USB行为尚未验证，文件系统阻塞不能被本层抢占。`wire_bytes`计入已接受的请求/读取字节，`Budget.used`只计材料载荷；空传输只占读取次数与时间。

## 已知错误、未知结果与退出

- 尚未 begin 的固定名称/Sink 配置拒绝：本地拒绝，没有模拟发送。
- begin后的发送中断由调用方abort；非空短头、错误序号、超限、未收齐声明内容、接收超时/中断或载荷写失败：协议未知，禁止后续读取和退出许可。完成后又主动向解析器喂入非请求结果同样转未知。
- 按声明长度收齐全部响应后，非成功response/Jiritsu status、精确长度不符或主机finish/fsync失败：保留已知完整响应，但停止新读取。期限及线路预算仍允许时，最多消费一次本地健康退出许可。
- `claim_exit()` **不发送任何命令**。实际服务退出还必须先持久化意图，并遵守认证状态、同端口及正常身份复核；不能用这个许可绕过日志失败或替代 C5。

被动解析器保留旧结果字段：`simulation_only`为true，`physical_protocol_verified`、`response_profile_verified`、`camera_operations_performed`均false。本层不能认定输入来源；实际设备活动由外层采集报告单独记录，不能拿这些旧字段声称整个采集没有设备操作。88字节及命令成功不是型号、版本或程序认证；完整程序SHA、BK4、UXC、C0–C5顺序与新鲜度仍由上层检查。

## 必须保留的协议证据缺口

固定 PMCA 只校验响应序号。本模型额外要求 pFunc 回显、version/miconType/offsetType 为零，**这是保守实验限制，尚无 A7C II 真实响应证明**，可能拒绝合法机身响应；不能称已验证协议。也没有把每段 size 必须递减当成协议事实：沿用 `min(size,1MiB)` 和 `size>1MiB` 续段规则，再独立限制声明/累计大小与段数。

第73轮已复现旧主动排空丢弃有效续块、缺尾空包不结束及包头前空传输被拒绝；第74轮修正并加入按实际读取顺序排队的离线测试。只接入文件/快照所需的无主动排空路径，未接入上游直接CP参数读取的特殊结束包流程、自动重认证或救援。包头仍须一次非空返回完整12字节，不因允许空传输就接受非空短头。真实传输边界仍需受控验收，修复不能解释尚未进入材料阶段的旧MSC身份错误。
