# 验证记录与边界

本页保留来源仓库 [MDHan/a7c2-fl23-macos](https://github.com/MDHan/a7c2-fl23-macos) 的固定提交与前身脚本验证记录，不代表新增 LUT 研究已通过相机验证。机内 LUT 照片直出尚未实现；当前研究验证见 [轮次记录](../research/ROUNDS.md)。

## 实机证据来源

2026-10-18，前身机身专用脚本在一台 Sony ILCE-7CM2、原版 2.01 和 MacBook Air M4 上完成：

- 正常存储接口权限检查、动态相机磁盘识别、普通卸载和 libusb 接管。
- 两次服务认证、型号与机身身份匹配、同一 USB 物理端口绑定。
- 原始 AP/CP、当前及保存设置的两份备份，共8个文件/份；两份均在同一台Mac，不能视为物理容灾。
- 原始程序指纹、候选全文件哈希及反向还原核验。
- 机内预检查，实际安装40个固定窗口，完整程序读回、保存参数核验、WBI处理。
- 冷启动后完整程序、保存参数和6处运行区域核验；退出服务后普通USB返回。
- 使用者确认 FL2/FL3 菜单出现，ST/FL2/FL3 新照片拍摄与回放正常。

公开仓库仅记录以上结论，不收录该机身原始数据或含个人信息的日志。

## 实际遇到的问题

1. sudo 仍报权限不足：通过确认相机磁盘、普通卸载及临时驱动接管解决。
2. 机内预检查完成后再次进入安装时磁盘尚未稳定：正式写入前停止。人工核对无写入后，加入磁盘稳定等待，单次受限续接后完成安装。
3. 安装主体完成后等待普通USB身份超时：人工复核程序、参数保存和WBI证据后，冷启动并完成验证。

通用化代码不会移植当时绑定具体机身、目录、失败文件哈希的续接开关；未知结果仍停止。只有当前调用中、操作主体正常返回且服务退出成功后的普通USB等待超时，才允许独立记录 `*_usb_unconfirmed`。

结果为 `verified_after_cold_start`：

## 本仓库离线测试与剩余边界

通用化重构使用固定上游源码/资产，不改补丁窗口。自动测试覆盖动态磁盘枚举、USB生命周期、超时/中断停止、阶段控制、归档校验和合成备份流程；上游附带的离线测试另行执行。

2026-10-18 本地验证：30 项 Mac 适配测试、8 项上游离线测试全部通过，固定版本下载及逐文件/资产校验通过。默认单份备份和可选额外副本分别有测试；这些测试不访问真实USB。

终端简体提示适配后，本地重新通过 33 项 Mac 适配测试和 8 项上游离线测试。新增检查覆盖实际读回提示、失败退出码不变，以及动态路径和身份标识不被转换；固定上游文件哈希核验通过。转换仅用于终端显示，原始诊断记录保留原文，本次没有操作相机。

**本仓库尚未再次向机身固件/设置写入，也没有第二台机身验证。** 通用版默认单份备份创建、首次安装和恢复仍只有离线测试；不能将前身脚本的安装实测归为本仓库这些路径的实测。

尚未验证：Intel Mac、其他 Apple Silicon 组合、恢复原版的真实操作、断电/断线救援、全套视频与照片模式、长期稳定性、与其他型号官方FL2/FL3的严格色彩一致性。离线测试通过不能替代这些实机验证。
