# 单槽、单风格摄影验收工作表

这是一份现在可填写的准备表，**不是已完成实拍或可直接交CLI的JSON**。正式相机操作留D4–D6；当前无需升级/连接机身。已有[配对标定/冻结验收工具](NATIVE-VALIDATION.md)不重写，实际数据按其契约录入。演示数值不是摄影质量标准，空项不能记为通过。

## 先确定一种风格

| 项目 | 填写内容 |
| --- | --- |
| CUBE与来源/授权 | 待填写文件名、哈希及来源；保留私人位置，不上传素材 |
| 输入/输出色彩域 | 待填写；有非ST输入时记录桥接及测量依据，不能只改标签 |
| 暂定模型/响应依据 | 待填写；单位矩阵不算本人Sony ISP响应测量 |
| 软件筛选结果 | 待填写preview输出、整体/分区误差、触限/裁切及可见问题；只属于机外模型 |
| 目标槽位/名称 | 只选择一个；实际机身来源与程序身份由D4/D5核验 |

有两三个候选时，使用同一参考图、相同暂定模型/域/阈值做比较，先淘汰明显超限或不喜欢的方案，再选择一种。不能因预览好看就声称机内等效。

## 拍摄前记录与分组

| 项目 | 填写内容 |
| --- | --- |
| 机型/固件/实际源状态 | 待填写实际结果；2.00与2.01分别记录，不混为一个已验证模型 |
| 拍摄设置 | 待填写曝光、白平衡、色彩空间、ST及所用风格参数；配对时保持可比 |
| 光源/场景条件 | 待填写光源、位置/稳定性、场景与光线变化；不能仅凭场景ID证明独立 |
| 响应测量场景 | 待填写；response_matrix需另行测量依据，不由ST/RAW配对自动估计 |
| 标定训练场景 | 待填写train IDs及配对/对齐/RAW显影依据 |
| 标定留出场景 | 待填写holdout IDs，不能与训练复用同实景/裁片或改名重复 |
| 最终独立验收场景 | 待填写required IDs；排除训练、留出及响应场景，另拍/另选独立材料 |

正式标定数据需要真实ST与明确的linear ProPhoto D50参考/显影、配对/对齐说明；当前原生拟合只消费模型响应部分，不把已有逆ST曲线自动当作完整桥接。不能用普通sRGB照片替代线性参考，或拿其他机型的矩阵补未知。

## 先约定标准，再看最终验收

| 项目 | 预先填写的标准 | 实际结果 |
| --- | --- | --- |
| 标定留出 | 线性ProPhoto MAE上限及每场景规则 | 待验证 |
| 每张独立图整体 | 最少样本、RGB MAE上限、Delta E76 P95上限 | 待验证 |
| 肤色、灰阶、绿植、天空 | 各区最少样本及上述误差上限，显式掩码 | 待验证 |
| 高光、阴影、饱和颜色 | 各区最少样本及误差上限，显式掩码 | 待验证 |
| 表达边界 | 收敛要求、系数触限数上限、预测裁切通道比例上限 | 待验证 |
| 人工观感 | 肤色自然感、风格统一、反差/高光/阴影偏好及可接受问题 | 待验证 |
| 机内一致性 | 同条件实时预览、JPEG、回放、冷启动表现 | 待验证 |
| 保留与恢复 | 其余槽/设置、实际恢复操作的已证范围与未证部分 | 待验证 |

区域可分散在不同场景，某张图没有肤色就留空；所有必需区域最终需有有效掩码/足量样本。缺失、采样不足和超限分别记录，不用好场景平均掩盖差场景，不把图片P95平均当整体P95。人工观感和数值各自记录，不能互相补为通过。

## 数据处理顺序

先准备项目/模型、配对标定说明、场景/掩码及阈值；再用原nativevalidate.freeze冻结；拟合时显式传入同一validation-lock；最后用原benchmark核对独立场景。具体可运行命令和JSON字段见[NATIVE-VALIDATION](NATIVE-VALIDATION.md)，这里不增加新格式/检查器。

更换模型、CUBE/桥接、阈值、图片或掩码后使用新输出重新冻结/拟合，不覆盖旧报告。现有软件能核对文件内容与声明，不能认证实景独立性、真实光源或实际机内执行。真实拍摄、同机材料及机身效果仍等待D4–D6，本表不放行安装或代替内部备份。
