## PRIVATE的来源和发布保护

本人本轮说明根目录PRIVATE拷贝自相机保存设置。当前只记录为**用户声明的相机菜单设置副本**，未读取/解析其内容，未认证文件类型、机型、版本、完整性或可加载性。根.gitignore新增`/PRIVATE/`，避免这类私人菜单文件被普通git add纳入；已有文件不搬移、不重命名、不覆盖、不上传。忽略规则不是文件备份，也不能防止显式强制加入。

菜单设置副本用于保留日常设置；它不能补充同机AP/CP程序、RAM/保存BK4、68份UXC、内部恢复/降级或独立介质证据，不改名交给内部材料检查器。跨版本加载兼容性仍按[日常备份指南](BACKUP-GUIDE.md)中的官方说明处理，不能承诺2.00设置在2.01全部恢复。
